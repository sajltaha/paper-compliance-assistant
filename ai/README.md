# Criterion evaluation module

This module is planned to normalize confirmed conference criteria, combine supported rule checks with LLM evaluation, and validate result structure and evidence references.

Implementation is tracked in PCA-19. The result schema is in docs/ai_contract.schema.json; requirements, failure handling and evaluation procedures are in docs/06_requirements.md, docs/API_CONTRACT.md and docs/09_evaluation.md.

No model calls or working evaluation pipeline are implemented in this directory. The prototype findings are synthetic examples.
